# SAEP Estoque Fácil 
 
Sistema simples desenvolvido no Hackathon SAEP para controlar produtos de uma loja. 
 
## Situação-problema 
 
Uma pequena loja de materiais escolares controla seus produtos em papel. Isso causa perda de informações, erros de 
quantidade e dificuldade para saber quais produtos estão acabando. 
 
## Objetivo do sistema 
 
Criar um sistema simples para cadastrar, listar, excluir e verificar produtos com estoque baixo utilizando Python, 
Tkinter e MySQL. 
 
## Tecnologias utilizadas 
 - Python 
 - Tkinter
 - MySQL - VSCode 
 
## Funcionalidades 
 - Cadastro de produtos - Listagem de produtos em tabela - Exclusão de produtos - Validação de campos obrigatórios - Validação de quantidade e preço - Verificação de estoque baixo 
 
## Testes realizados 
 
| Teste | Resultado esperado | Resultado obtido | 
|------|--------------------|------------------| 
| Cadastrar produto válido | Produto aparece na tabela | Funcionou | 
| Tentar cadastrar campo vazio | Sistema mostra alerta | Funcionou | 
| Digitar quantidade inválida | Sistema mostra erro | Funcionou | 
| Verificar estoque baixo | Sistema lista produtos com quantidade menor que 5 | Funcionou | 
| Excluir produto | Produto selecionado é removido | Funcionou | 
 
## Conclusão 
 
O sistema atende aos requisitos principais da situação-problema, permitindo cadastrar, listar, excluir e verificar 
produtos com estoque baixo. O projeto demonstra o uso de interface gráfica, banco de dados, validação e testes 
básicos.
